## What I'm About

- **Backend systems** - NestJS, Django, FastAPI. I've built everything from healthcare orchestration pipelines to microservices powering recipe recommendations with graph databases.
- **AI agents** - multi-agent architectures, RAG pipelines, LangGraph, context engineering. I built VINA, a mental health AI companion with semantic routing and human-in-the-loop escalation for high-risk users.
- **Web3 & smart contracts** - Solidity, Hardhat, Ethers.js. I'm actively building on Ethereum and L2s, exploring decentralized systems that remove the need for trust intermediaries.
- **Technical writing** - I write technical articles on the stuff some engineers avoid explaining.

## </> Selected Projects

### VINA - Mental Health AI Companion
*Python · FastAPI · LangChain · LangGraph · Mistral AI · Pinecone*

A multi-agent system built for 24/7 emotional support and early crisis intervention. Features semantic routing to specialized agents, a RAG pipeline grounded in verified mental health content, and a human-in-the-loop escalation path that surfaces licensed therapists for high-risk conversations. Deployed via FastAPI WebSocket for real-time, low-latency interaction.

[→ GitHub](https://github.com/Vina-Ops/vina)

---

### FairShare - Decentralized Expense Splitter
*Solidity · Hardhat · Ethers.js · Base L2 · TypeScript*

A trustless, on-chain expense-splitting contract deployed on Base Sepolia. Groups record expenses, balances update automatically, and members settle debts in ETH directly - no intermediary, no trust required. Gas-efficient architecture with full on-chain auditability.

[→ GitHub](https://github.com/Princeigwe/fairshare) · [→ Base Explorer](https://sepolia.basescan.org/address/0x7027379c68ce3f4CD3E6779B042a355F222AD5Ba)

---

### Nutranova - Wellness Recipe Platform
*Python · Django · GraphQL · Neo4j · RabbitMQ · Redis · Docker*

A microservices-based recipe platform with event-driven feed generation via RabbitMQ, GraphQL Federation via Apollo GraphOS, and intelligent recommendations powered by Neo4j graph traversal and vector similarity search.

[→ GitHub](https://github.com/Princeigwe/NutraNova)
